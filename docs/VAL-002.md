# VAL-002 — Value-Source Decomposition

> **Status:** FROZEN CANDIDATE  
> **Scientific authority:** validation / control definition only  
> **Quality authority:** NONE  
> **Performance authority:** NONE

## Question

Can this repository represent the historical Value Embeddings mechanism faithfully
while also defining a separate control family that isolates the two algebraic
ingredients changed by Memory Attention?

Those are different goals and therefore use different lanes.

## Source finding

embeddings*.


with learnable lambda initialized to 0.5 in the preserved record.

## Why two lanes are required

A source-faithful historical comparison and a causal control are not the same
object.

### Lane H — historical/source fidelity

~~~text
H0 Standard:
    V = Vproj

H1 Historical Value Embeddings:
    V = (1-lambda) * Vproj + lambda * E[token]

H2 Memory Attention reference:
    V = Kcontent + M
~~~

The historical lane preserves the prior mechanism's fusion rule.

It does not by itself isolate why H2 differs from H0 because both contextual
source and fusion/scaling differ.

### Lane C — local causal factorial

~~~text
C00 = Vproj
C01 = Vproj + M
C10 = Kcontent
C11 = Kcontent + M
~~~

Here M is the exact same frozen Memory Attention contribution in C01 and C11.

C01 is a **local experimental control**.

It is not the historical Value Embeddings method.

## Atomic factors

~~~text
contextual source
    Vproj
    Kcontent

Memory Attention memory contribution
    absent
    present
~~~

At fixed inputs the four cells imply:

~~~text
memory effect from Vproj:
    C01 - C00 = M

memory effect from Kcontent:
    C11 - C10 = M

contextual-source effect without memory:
    C10 - C00 = Kcontent - Vproj

contextual-source effect with memory:
    C11 - C01 = Kcontent - Vproj

fixed-input additive interaction:
    C11 - C10 - C01 + C00 = 0
~~~

The zero interaction is an algebraic property of this local additive control
family.

It is **not** a claim that training dynamics have zero interaction.

## Frozen fixture

The VAL-002 fixture reuses the frozen VAL-001:

~~~text
Kcontent
M
Kcontent + M
~~~

and adds:

~~~text
a synthetic projected V
a separate historical token-value embedding fixture
historical lambda = 0.5
~~~

The historical token-value fixture is intentionally distinct from the Memory
Attention memory contribution.

This prevents the test harness from accidentally treating the two lanes as
the same construction.

## Decision support

DS-003 records the Council decision.

The Monte Carlo stress test compares:

~~~text
historical-only
factorial-only
dual-lane
broad-zoo
~~~

The dual-lane design wins the balanced, source-heavy, causal-heavy, and
future-training-heavy scenarios.

A scope/cost-heavy stress case prefers the smaller factorial-only design.

This counterexample is retained so the dual-lane design is not mistaken for a
universal optimum.
